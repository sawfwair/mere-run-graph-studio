# Support

Use GitHub issues for reproducible Graph Studio defects and focused feature
requests. Before opening one, search existing issues and include:

- Graph Studio version or commit;
- operating system and architecture;
- relevant `mere.run` and workflow-tools versions;
- expected and actual behavior;
- minimal graph or steps that contain no secrets or private data;
- diagnostics or logs with paths, tokens, and account details redacted.

General `mere.run` execution, provider, Relay, or Mere World questions may
belong in the repository that owns that component. See the ownership table in
the [README](README.md#ownership).

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not be
reported in a public issue. Community conduct concerns follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
